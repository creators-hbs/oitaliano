# O Italiano

O Italiano - Consultoria Imobiliaria e Financeira.

Site institucional estatico multipaginas, preparado para GitHub e Vercel a partir da raiz do repositorio.

## Instalacao

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

O servidor local abre em `http://localhost:4173`.

## Build

```bash
npm run build
```

O build gera a pasta `dist/`.

## Validacao

```bash
npm run validate
npm run validate:dist
```

## Deploy

Importe o repositorio diretamente na Vercel usando a raiz padrao.

- Framework Preset: Other
- Root Directory: ./
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
